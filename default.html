Electron Vite Project

基于 Electron + Vite + Vue 3 + TypeScript 构建的现代化跨平台桌面应用程序

技术栈

⚡

Electron

跨平台桌面应用框架，使用 Chromium 和 Node.js 构建原生应用

⚛️

Vue 3

渐进式 JavaScript 框架，组合式 API 和 TypeScript 支持

🔧

Vite

下一代前端构建工具，极速的开发服务器和热模块替换

📘

TypeScript

JavaScript 的超集，提供类型检查和面向对象编程能力

核心特性

🚀 极速开发体验

Vite 提供的即时开发服务器启动和热模块替换，让开发效率提升数倍。修改代码即可实时预览，无需手动刷新。

🔒 安全隔离架构

采用 Context Isolation 和 Preload Scripts 设计，有效隔离渲染进程与主进程，保护应用安全。

📦 高效打包构建

利用 electron-builder 进行应用打包，生成跨平台可执行文件，支持 Windows、macOS 和 Linux。
